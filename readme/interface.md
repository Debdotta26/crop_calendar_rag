# 🌱 India Crop Calendar AI Portal

An AI-driven agricultural information extraction and visualization platform for analyzing Crop Weather Watch Group (CWWG) reports from the Ministry of Agriculture, India.

## 📖 Overview

The India Crop Calendar AI Portal is a comprehensive Streamlit-based web application that processes, analyzes, and visualizes agricultural data extracted from CWWG reports. It provides actionable insights into crop cultivation patterns, pest outbreaks, weather impacts, and regional agricultural activities across India.

### 🎯 Key Features

| Feature | Description |
|---------|-------------|
| **📊 Dashboard** | Interactive overview with key statistics, crop distribution charts, and state-wise analysis |
| **🔍 Smart Search** | AI-powered search across all reports with relevance scoring and contextual results |
| **📋 Evidence Logs** | Detailed record viewer with filtering, search, and source document linking |
| **📈 Analytics** | Comprehensive visualizations including crop, state, season distributions and correlation matrices |
| **📅 Crop Calendar** | Consolidated calendar showing sowing, growing, and harvesting periods |
| **🐛 Pests & Diseases** | Tracking of pest and disease occurrences across crops and regions |
| **📊 Calendar Matrix** | Week-by-week aggregated timelines of crop stages and advisories |
| **🌾 Crop Timeline** | Start/end dates, growth stages, and regional activity schedules |
| **⚠️ Events Tracking** | Monitoring of crop destruction events (flood, drought, pest attacks, etc.) |
